 # Sistema de Cálculo de Horas Complementares
## Sistema web para registro e cálculo automático de horas complementares acadêmicas, desenvolvido para facilitar o acompanhamento das atividades extracurriculares exigidas pelo curso.

# Objetivo
## Auxiliar estudantes a gerenciar suas horas complementares, permitindo  o controle do progresso e a verificação do cumprimento da carga horária exigida pela instituição.
